# SNS Trend Manga Analyzer

このスキルは、SNS上の特定のテーマに関する話題を深く掘り下げ、論理的な分析結果と、それを視覚的に分かりやすく伝える4コマ漫画を生成するためのワークフローを提供します。

## ワークフロー

### 1. SNSトレンドの抽出
- 指定されたテーマに基づき、SNS（主にX/Twitter）から最新の投稿や話題を5つピックアップします。
- 抽出の際は、リポスト数やいいね数だけでなく、内容の独自性や議論の深さを重視します。

### 2. 調査・分析
- ピックアップした各トピックについて、以下の項目を調査・分析します。
  - **背景**: なぜその話題が注目されているのか。
  - **構造**: その話題を構成する主要な要素や対立軸。
  - **根拠**: 統計データ、ニュース記事、専門家の意見などの客観的な裏付け。
  - **影響**: その話題が今後どのような変化をもたらす可能性があるか。

### 3. 4コマ漫画の構成案作成
- 分析結果を元に、各テーマごとに4コマ漫画のストーリーを構成します。
  - **1コマ目（起）**: 現状の提示や問題提起。
  - **2コマ目（承）**: 展開や具体的な事例。
  - **3コマ目（転）**: 意外な事実や分析による発見。
  - **4コマ目（結）**: 結論や今後の展望。

### 4. 4コマ漫画画像の生成
- `generate` モードを使用し、1枚の画像内に4コマが収まった形式で漫画を生成します。
- プロンプトには「4-panel comic strip layout」「manga style」「Japanese text (if possible)」などのキーワードを含め、視覚的な一貫性を保ちます。

## 使用ツールとガイドライン

- **ブラウザ**: SNSの最新情報を取得するために使用。
- **検索**: 背景知識や根拠となるデータの収集に使用。
- **画像生成**: 4コマ漫画の生成に使用。
  - プロンプト例: `A 4-panel comic strip about [Theme], manga style, black and white, clear panels, showing [Story details].`

## 注意事項
- SNSの投稿は個人の意見が含まれるため、必ず複数のソースで事実確認（ファクトチェック）を行ってください。
- 画像生成において、特定の個人や団体を誹謗中傷するような内容は避けてください。
- 4コマ漫画内のテキストは、画像生成AIの特性上、正確に描写されない場合があるため、補足としてテキストでも内容を提示してください。
